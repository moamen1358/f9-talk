## [0.8.0] - 2026-10-02 - AssemblyAI, a Settings window, no more cut sentences

### Added
- **AssemblyAI Universal-3.6 Pro Realtime** is the new default speech-to-text service. Deepgram Nova-3 is still one click away.
- **Settings window** (right-click the red dot, the apps-menu "Settings" action, or `f9-talk settings`): choose the service, paste each API key (masked, with Show), check it with **Test key**, pick the language, edit your key terms and the connection time. Save applies at once, with no restart.
- **Bring your own key, guided:** on first run with no key, Settings opens by itself with links to get a free key (AssemblyAI gives free credit on sign-up, Deepgram $200).
- **Key terms:** a list of names and jargon (GitHub, Kubernetes, `.env`) that both services spell right.
- **Language:** English (default), Spanish, French, German, Italian or Portuguese.

### Fixed
- **The end of a sentence was sometimes not typed.** Release used to wait a fixed 350 ms; now F9 Talk asks the service to finish and waits for the complete final text (usually 0.2 to 0.4 s).
- **A pause mid-sentence split one dictation into separately punctuated pieces** ("The tokenizing model. Works correctly."). One press now gives one sentence.
- The last few milliseconds of audio before release could be dropped.
- Deepgram rejected boosted words with HTTP 400 (`keywords` is now `keyterm`).

### Changed
- API keys saved in Settings go into the desktop keyring (Secret Service), or `~/.config/F9_talk/secrets.env` with mode 600 when no keyring runs. Existing `secrets.env` keys and the `ASSEMBLYAI_API_KEY` / `DEEPGRAM_API_KEY` environment variables keep working.
- The AssemblyAI connection closes 60 s after your last dictation (it bills while open) and reopens on the next press without losing a word.
- Em and en dashes in the transcript are typed as plain hyphens.
- Launching F9 Talk while it already runs opens Settings.
